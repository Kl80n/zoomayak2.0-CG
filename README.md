# ЗооМаяк

Цифровой профиль питомца и экосистема заботы: ветеринарный паспорт с QR-кодом,
напоминания о прививках, медицинская история, SOS-поиск потеряшек, студия
адресников и каталог объявлений.

## Стек

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4 (через `@tailwindcss/vite`)
- `qrcode.react` — генерация QR-кодов
- `@zxing/browser` — сканирование QR через камеру
- `lucide-react`, `motion`, `canvas-confetti` — иконки и анимация

Данные MVP хранятся локально в браузере (`localStorage`) через `src/storage.ts`;
серверная часть подключается отдельным этапом.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение поднимается на `http://localhost:3000`. Переменные окружения не нужны.

Доступные скрипты:

| Скрипт | Действие |
| --- | --- |
| `npm run dev` | Дев-сервер Vite на `0.0.0.0:3000` |
| `npm run build` | Продакшен-сборка в `dist` |
| `npm run preview` | Локальный просмотр собранного `dist` |
| `npm run typecheck` | Проверка типов через `tsc --noEmit` |

## Деплой на Vercel

Настройки берутся из `vercel.json`:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

Все маршруты переписываются на `/index.html`, поэтому публичные страницы вида
`/qr/<ZM-ID>` работают при прямом заходе по ссылке.

## Структура репозитория

Корень репозитория — это и есть корень Vite-проекта. `package.json`,
`index.html`, `src/` и `public/` должны лежать в корне, иначе Vercel не найдёт
проект. Не создавайте внутри репозитория вложенные папки с копиями версий.

```text
index.html            точка входа Vite
metadata.json         манифест приложения (имя, описание, разрешения)
src/
  App.tsx             корневой компонент, роутинг вкладок и публичной /qr/<ID>
  brand.ts            пути к утверждённым логотипам
  types.ts            модель данных (питомцы, записи, напоминания, объявления)
  storage.ts          состояние с сохранением в localStorage
  components/         экраны, вкладки и модальные окна
  data/               демонстрационные данные и каталог объявлений
  services/           парсер каталога объявлений
public/               статические ассеты, включая логотипы
docs/logo.md          инвентарь и правила использования логотипа
CHANGELOG.md          история версий
```

## Разделы приложения

- **Главная** — Hero с выбранным питомцем и быстрые переходы в разделы.
- **Мои питомцы** — список питомцев, паспорт, студия адресника.
- **Напоминания** — прививки, обработки, визиты к врачу.
- **Здоровье** — медицинская история и вложения.
- **Потеряшка SOS** — объявления о пропаже, отчёты о встречах с геолокацией.
- **Объявления** — каталог животных и услуг с источниками Avito / VK / Telegram / ЗооМаяк.
- **Личный кабинет** — профиль владельца и настройки публичности контактов.
- **`/qr/<ZM-ID>`** — публичная страница питомца, которая открывается по
  сканированию адресника; позволяет нашедшему отправить геолокацию владельцу.
